Your coding agent doesn't need you watching over its shoulder. Both Copilot CLI and Claude Code now let you steer a running session from your phone.

Waiting for the coffee machine? Approve that file edit. Walking to the canteen? Check if the tests passed. Taking ... "a moment of quiet reflection"? Review the diff. On a beach? Sure, why not — you're basically pair-programming with your sunglasses on.

Copilot CLI:
/remote on
Scan the QR code → steer from the GitHub Mobile app. Approve permissions, send prompts, cancel tasks.

Claude Code:
/remote-control
Session appears in the Claude app. Full prompting + push notifications when the agent needs you or finishes a task.

:warning: Your machine must be on (locked, of course, since you are AFK). (And "View and control" must be enabled by admin.)

💡 Try this: Start a task, type /remote on (or /rc), go enjoy a coffee :coffee:  or an :icecream: with a colleague, check in through the phone app.
